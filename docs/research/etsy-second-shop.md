# Etsy: second shop on one account, or a second account

Refs #7. Source: Etsy Help Centre, retrieved 2026-10-08 from
<https://help.etsy.com/hc/en-us/articles/360017604474-How-to-Open-a-Second-Shop-on-Etsy>

## Answer

ONE SHOP PER ACCOUNT

> This is because each Etsy account can only have one shop and one email address at a time.

> No, we don’t have a way to move shop info from one account to another or combine shops on one account.

Source: <https://help.etsy.com/hc/en-us/articles/360017604474-How-to-Open-a-Second-Shop-on-Etsy>, retrieved 2026-10-08.

## Second account

Etsy permits one person to hold several accounts, one per shop:

> To run more than one shop, create a new Etsy account with a different email address, and open a new shop on the new account.
>
> You’re welcome to run multiple shops at once on Etsy.

Conditions stated on the same page:

> If you choose to run multiple shops on Etsy, you must list all the shops you run in the Public Profile section of each account. Each account must also comply with Etsy’s Seller Policy.

> Yes, you can use the same credit card for seller registration as well as the same bank account if you sign up for Etsy Payments.
>
> You must use the same taxpayer ID and address when applicable.

Source: <https://help.etsy.com/hc/en-us/articles/360017604474-How-to-Open-a-Second-Shop-on-Etsy>, retrieved 2026-10-08.

Not covered: the page names no clause that forbids a second account. The Terms of Use

## What this forces

- Several trios means several Etsy accounts, each with its own email and its own shop (#11).
- No second identity, bank account or tax registration is needed: same card, bank account, taxpayer ID and address are allowed.
- Every shop must list all sibling shops in its Public Profile.
